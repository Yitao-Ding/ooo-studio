Our own products. Claude Code writes and tests most of the code, and Claude runs inside the apps where a model does the work better than a form.

Project Agent

A team app for student groups.

Circles, seminars and volunteer teams run several projects at once, and the work gets lost in group chats. Project Agent keeps it as group, project, team and task, and keeps a record once a project ends.

Claude
Built by Claude Code agents with separate jobs: planning, building, QA and design review. Next: Claude writes the project recap when a project closes.
Stack
Expo, React Native, Supabase
Status
TestFlight, App Store submission in progress

News Globe

The day's world news, placed where it happened.

A 3D globe with the day's stories pinned to their locations and ranked like a front page. Switch between map and satellite, zoom in, and read the summary next to the place.

Claude
Reads the RSS feeds, writes the summaries, sorts each story and works out where it happened.
Stack
CesiumJS, Natural Earth, Vite
Status
In development

Bitaw

Cebuano speaking practice.

Type or say a sentence in Japanese and get natural Cebuano back, with its structure, pronunciation and audio. Pronunciation is scored on the phone.

Claude
Generates lessons and runs conversation practice. Moving to the Claude API next.
Status
TestFlight

Lecture Hub

Notes, tasks and recordings for each class in one place, with search by meaning and new lecture pages set up every week.

Claude
