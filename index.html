Lecture Hub

A notebook for university lectures

A Notion-style workspace for my university classes. Lecture notes, tasks and a chat in one place. Recordings are transcribed, every page is searchable by meaning, and new lecture pages set themselves up each week.

vidkit

Turns a video into text Claude can read

A command-line tool that turns a video into something Claude Code can read: transcript with speakers, scene cuts, frames and chapters. Five modes (dance, lecture, autocut, tighten, tutorial), with FCPXML export for Final Cut Pro.

Claude
The analysis runs inside a Claude Code session. Claude Code also wrote most of the tool.
Stack
Python, MLX-Whisper, pyannote, ffmpeg

Project Agent

A team app for student groups

A team app for student groups: circles, seminars, volunteer teams. Work is organised as group, project, team and task, and when a project ends it stays as a record instead of sinking in a chat log. iOS, Japan first.

Bitaw

Cebuano speaking practice

A Cebuano speaking app for me and two friends before a trip to Cebu. Type or say a sentence in Japanese and get natural Cebuano back, with its structure, pronunciation and audio. Pronunciation is scored on the phone.

Claude
Lessons and conversation practice are generated by Claude, today through a small relay on my Mac.
Next
Moving to the Claude API, so practice works without my Mac switched on.
Stack

News Globe

The day's news, placed on a globe

A 3D globe that pins the day's world news where it happened, ordered like a newspaper front page. Map and satellite views, place names that stay sharp at any zoom. Original features are being added next.

Claude
Claude reads the RSS feeds, writes the summaries, sorts each story and works out where it happened.
